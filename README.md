# Tidyline Cleaning Co. — FireWorks Template

Reusable residential and commercial cleaning website template with seven crawlable pages, recurring service plans, a detailed quote intake, explicit task boundaries, and provider-ready scheduling and recurring-billing gates.

All business names, contact details, coverage, hours, credentials, reviews, availability, prices, and service claims are sample content. Demo forms validate locally and do not send, store, upload, book, or charge anything.

Run `npm test` to verify links, metadata, demo safety language, required intake fields, local assets, and provider gates.
